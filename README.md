# sumi

一个纯白、极淡蓝与深色文字的极简个人订阅管理网站。应用使用静态 HTML、CSS 和 JavaScript，无需构建或安装生产依赖，可部署到 GitHub Pages。

## 部署到 GitHub Pages

1. 正式发布前运行 `python scripts/update-pwa-cache.py` 更新静态资源校验清单。发布仓库根目录全部运行时 `.html`、`.css`、`.js`、`manifest.webmanifest`，以及完整的 `locales/`、`assets/`；保留相对路径、品牌来源与许可证文件。必须一次发布相互匹配的文件，不能遗漏 `sw-assets.js`。
2. 进入仓库 **Settings → Pages → Build and deployment**，Source 选 **Deploy from a branch**，Branch 选正式发布分支，文件夹选 `/(root)`，保存。
3. 等待 Pages 部署完成，打开 GitHub 显示的网站地址。

以上是将来正式发布所需的文件与步骤；第六阶段不部署正式版本。开发阶段的 Draft PR 按依赖关系审查，未经统一验收和明确授权不提前合并到 main。

## 当前实现

- 首页、独立统计页、订阅列表、日历与设置；保留桌面左侧导航和手机底部导航。
- 手机首页使用紧凑摘要，隐藏月度柱状图，完整保留到期与逾期提醒；桌面和宽屏 iPad 保留图表。
- 订阅新增、编辑、类别管理、取消与恢复；72 项预置服务、中文/英文/别名搜索、品牌 Logo 选择及自定义图片上传、替换和移除。
- 月底、闰年、跨年及不同周期的账期；成功/失败付款、补录、编辑、删除和重复确认保护。
- 多币种原币金额、统计展示币种、参考汇率缓存及确认付款时的冻结换算。
- 月度平均成本、年度摊销成本、服务/类别占比、实际付款金额与次数；支持月份、年份和自定义日期范围。
- JSON 备份/恢复及浏览器 localStorage 持久化；图片优先 IndexedDB，异常数据保护和失败保存恢复。
- 可安装的 PWA、完整静态资源离线缓存、校验通过后主动确认更新；离线仍可管理本地订阅和付款。
- 统一轻量动画、减少动态效果设置、可见视口适配软键盘；列表搜索保留输入节点，复用搜索索引与 Intl 格式化器。
- 简体中文、繁體中文、日本語与 English 界面；即时切换并保存选择，日期、数字和金额按语言显示。
- 浅色、深色及跟随系统三种外观；默认浅色，手动选择持久化，系统模式响应外观变化。

## 安装、离线和更新

通过 HTTPS 或 localhost 打开后，应用会缓存完整静态资源。设置页显示离线准备状态、安装入口（浏览器提供时）和更新检查。Safari 可按页面说明使用「添加到主屏幕」。首次离线使用前必须成功联网打开并完成缓存；关闭所有窗口后，等待中的新版本也可由浏览器自然启用。

已有窗口不会自动刷新。手动应用更新前需要关闭其他 sumi 标签页并保存/关闭表单；更新下载或校验失败时继续使用旧版。缓存不代理 Frankfurter，也不保存付款数据；业务数据仍由原存储和恢复逻辑管理。更新策略与缓存清单维护见 [PWA 记录](docs/pwa.md)。

设置中的「动态效果」支持跟随系统或减少动态效果；系统要求减少时始终尊重系统。动画只在实际切换页面、打开/关闭弹窗等操作时执行，汇率刷新和输入时不重复播放。软键盘适配依据可见视口，真实 iOS/iPadOS 仍需验收。详情见 [动态效果记录](docs/motion.md)。

## 语言与外观

在「设置」中选择 `zh-CN`、`zh-TW`、`ja-JP` 或 `en`，界面会立即切换，重新打开应用仍保留选择。默认使用简体中文。页面、订阅与付款弹窗、续费确认、Logo 选择器、错误提示和空状态共用集中管理的翻译资源；缺少当前语言的文案时回退到简体中文，再回退为本地化通用提示，不显示翻译键或 `undefined`。

日期、数字、百分比及货币显示使用 `Intl`。本地化只作用于显示：日期输入和持久化仍使用原 ISO 日期；订阅名称、备注、金额、付款记录、账期和汇率快照不会翻译或重算。已知订阅类别可以显示译名，存储继续保留原类别值；自定义类别和服务品牌名称保持原文，原有中英文与别名搜索继续可用。

外观可选浅色、深色或跟随系统。默认浅色保留原有纯白、极淡蓝设计；深色使用深灰背景、清晰文字、细边框和适度蓝色强调。品牌图片放在适合辨认的浅色底板上，不给品牌图形统一反色。「跟随系统」会响应系统外观变化；手动选择浅色或深色后不随系统切换。主题脚本在样式和应用渲染之前读取已保存选择，以减少首次加载时的主题闪烁。

语言和外观通过偏好设置专用保存路径持久化，保留原有恢复日志、失败回滚和过期页面保护；不会重新序列化旧订阅数据或写入成本观察。实现约定、维护方式与真实设备验收范围见 [国际化与外观记录](docs/i18n-theme.md)。

## 预置服务、搜索与 Logo

目录覆盖影音、音乐、AI、云存储、办公、游戏、设计、学习和开发工具，共 72 项服务。目录不保存或预填价格，用户仍可直接输入任意自定义服务名称。

在订阅名称中输入中文、英文或常见别名，会显示服务名称、Logo 和类别建议。支持方向键选择、Enter 确认、Escape 关闭及 Tab 离开，也处理中文输入法组合输入和触控选择。点击建议后填入服务名称及对应 Logo；类别为空或为「未分类」时才补入预置类别，已有金额、币种、周期与日期不变。白色建议面板位于表单内容中，避免覆盖下方关键输入项。

添加或编辑时点击 Logo 区域即可打开选择器，搜索品牌或上传自己的图片。从选择器挑选 Logo 会保留已有自定义名称；名称为空时才填入所选服务名。上传、替换和移除都先保存在表单草稿中，提交订阅后才持久化。移除后保留空 Logo，不因订阅名称恰好匹配品牌而自动恢复。

当前随站点保存 55 个有来源记录的真实 SVG 品牌图标；另外 17 项暂用统一中性 SVG 占位图，不以 emoji、首字母或生成图冒充品牌。列表、详情、统计和编辑表单使用同一显示规则。品牌资源随站点加载，不依赖运行时访问外部 Logo CDN；资源缺失或加载失败时显示中性图标。旧版明确匹配的 CDN 地址可在显示时映射至已有本地资源，不在启动时改写原存储。其他旧图标地址及自定义图片继续保留。

新上传支持静态 PNG、JPEG、WebP：原图不超过 12 MiB，单边最多 8192 像素，总像素不超过 4000 万。检查类型、签名、结构、尺寸和实际解码，再去除元数据并压缩至最长 512 像素、最多 300,000 字节；不接受 SVG、动画图和伪装类型。图片优先保存到 IndexedDB，事务成功后才把引用写入订阅；不可用时回退为压缩后的内嵌图片，仍由原保存流程处理容量失败。旧图片不自动迁移或重压缩。普通备份内嵌图片，导入优先恢复到 IndexedDB，避免图片占满 localStorage；缺失图片时阻止不完整导出并保留原记录。详情见 [图片存储记录](docs/logo-storage.md)。

来源、固定版本、许可信息、品牌使用限制及中性占位服务清单见 [品牌资源记录](docs/brand-assets.md)。资源包许可不等于商标授权，应用仅用品牌图标识别用户选择的服务。

## 统计口径

完整统计保留在导航中的「统计」页面，首页只展示简略摘要与桌面成本概览。

「按周期摊销的订阅成本」与「实际已支付」分别计算：

- 月度趋势是已记录日期中的平均月成本，按订阅金额和周期摊销；年度趋势累计已记录日期的摊销成本。服务和类别占比也使用所选期间的摊销成本。
- 成本观察保存原始金额、币种、周期、类别和状态的变更；统计展示时按当前可用的参考汇率换算，并标明部分日期及缺失汇率。
- 实际付款只统计成功记录，按实际付款日期筛选。付款次数不会因汇率缺失而丢失；无法统一换算的金额明确提示，同时保留原币金额。

旧数据没有完整的成本变化历史，系统不会把当前成本复制成过去各月的数据。尚未保存基线的旧订阅只代表今天的观察；可在统计页记录当前基线，后续变更持续追加历史。没有数据时显示空状态，不生成虚假趋势或占比。

## 多币种与参考汇率

每项订阅始终保存原始金额和原始币种；切换展示币种不会改写它们。默认展示币种为 CNY。接口提供的币种列表决定可换算范围，已有但未获接口支持的币种仍保留原币记录，并显示无法换算的原因，不以 1:1 替代缺失汇率。

使用用户指定的 Frankfurter v1：

- `https://api.frankfurter.dev/v1/latest`
- `https://api.frankfurter.dev/v1/currencies`

启动、页面恢复可见及周期检查时，每 24 小时判断是否需要更新；设置页可手动刷新。最近一次成功获取的参考数据缓存在本地，失败或离线时继续使用旧缓存，并显示汇率日期、最近成功获取时间和缓存状态。缓存的获取时间不等于参考汇率的日期，旧日期不会被改写成今天。

成功付款保存确认时的原币金额、原币币种、汇率、换算结果、付款日期及冻结汇率矩阵。之后刷新汇率不会改变该笔付款的换算结果；切换展示币种也只使用该笔已冻结的数据。若确认时无法换算，用户明确选择后可只保留原币金额，并记录缺失原因，不按未来汇率补算。旧付款未保存确认汇率时，也不凭当前汇率回填历史。

这些是每日参考汇率，不是秒级实时交易报价。v1 官方源码已标记 deprecated；本阶段按指定地址接入，没有擅自改成 v2。接口来源、结构、币种范围及真实联调限制见 [Frankfurter v1 接入记录](docs/frankfurter-v1.md)。

## 账期与付款规则

每个订阅保留原始扣款日：例如 1 月 31 日月付，经 2 月 28 日后会回到 3 月 31 日；按季、半年和年付同样处理短月、跨年与闰年。逾期付款逐期确认，不自动跳过未结清的月份。只有用户明确确认成功且本地保存成功后，才加入成功历史并推进至下一未付款账期。失败记录不计入实际付款，也不推进日期。本应用只记录结果，不会实际发起扣费。

补录可明确关联账期，也可留空、仅记历史；旧版未关联的补录不会被猜测归属。相同订阅和账期不能重复记录成功付款。删除或改为失败的关联成功付款会重新打开该账期；单独修改金额或实际付款日期不会重算账期。编辑历史原币金额时，只依据原有冻结汇率重新计算，不自动采用更新后的汇率。

显式修改下次续费日或周期，会以新日期建立扣款日基准，并将旧关联付款保留为旧账期历史，防止编辑或删除旧记录影响新计划。取消/恢复保留原账期和历史，不会跳到今天。旧数据未保存原始扣款日时，优先使用可匹配的历史账期，否则沿用当前日期；缺失信息不能被完整还原，可在编辑订阅时纠正。

## 本地开发与测试

运行 `python3 -m http.server 8000` 即可启动静态网站。开发验证方法、视觉基线、确定性接口模拟及异常数据恢复方式见 [tests/README.md](tests/README.md)。

继续使用 `sumi-data-v1`、`sumi-prefs-v1` 和 version 1 备份。旧数据在普通启动时不改写；导出备份保留付款冻结汇率及成本历史。汇率缓存使用独立的 `sumi-fx-cache-v1`，可重新获取，不替代业务备份。遇到异常数据时先导出原始内容，再用确认完整的备份恢复。

## 已知限制

- 安装到操作系统、真实 Safari/iPadOS 离线生命周期、存储回收和软键盘未通过真实设备验收；安装提示测试使用模拟事件。
- 浏览器清除或回收站点数据仍可能删除本地记录和图片，请保留完整 JSON 备份。导入文件上限为 50 MiB；无账号或云同步。

- 云环境对 Frankfurter 官网与 API 的真实请求被网络策略拒绝。用户已报告 iPad Safari 地址栏成功打开 USD/CNY 接口；这证明该设备直接访问可达，尚不能替代 sumi 网页内 fetch、CORS、缓存和手动刷新的验证。详见 [接入记录](docs/frankfurter-v1.md)。
- 真实 Safari、iOS/iPadOS、触摸键盘和系统字体仍待验收；现有尺寸检查使用 Linux Chromium。
- 原始扣款日和成本历史从未被旧版保存时，无法完整还原过去；历史付款没有确认汇率时不自动回填。
- 数据仅保存在当前浏览器，没有账号、云同步或支付平台接入。清理网站数据可能丢失记录，请定期导出备份。
- localStorage 不提供跨标签页数据库事务；严格同时写入的冲突解决仍需后续数据层设计。
- 部分预置服务尚无可靠本地 Logo，使用中性图标；真实品牌图标的来源及使用限制见品牌资源记录。
- 原生日期选择器、文件选择器及浏览器确认对话框的系统按钮语言由浏览器/操作系统控制；应用文案与校验提示使用已选语言。不同浏览器的本地化标点、货币间距与字体可能略有差异。
- 日历展示当前保存的下一次续费日期，不自动展开所有未来周期。
