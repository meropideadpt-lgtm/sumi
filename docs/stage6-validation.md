## 真实执行与模拟的区别

PWA 用例使用真实 Chromium Service Worker、CacheStorage、IndexedDB、localhost 静态站点与临时 `/sumi/` 子路径，实际执行离线新窗口、失败/损坏更新、手动更新和多标签保护。原生安装提示通过模拟事件测试按钮调用；没有进行操作系统级桌面安装。普通 UI/视觉上下文阻止 Service Worker，确保测试当前源码，不误用旧缓存。

Frankfurter 响应为确定性模拟；离线用浏览器网络模拟。云环境策略未允许实际访问 Frankfurter，未宣称实时联网/CORS 已验证。用户先前在 iPad Safari 地址栏访问 API 成功的结果不替代应用内 fetch、缓存及手动刷新验收。

模拟宽度覆盖 320、390、768/820、1440 像素；软键盘测试使用 VisualViewport 形状变化，不是真实键盘。真实 Safari/iPadOS 的安装、系统重启后的离线打开、照片方向/解码、内存限制、存储回收和软键盘仍待设备验证。

## 保留限制

- 浏览器站点数据被清除或回收时，本地业务和图片仍可能丢失；安装 PWA 不等于云备份。正常导出会包含图片及付款快照，导入上限为 50 MiB。
- IndexedDB 不可用时使用压缩内嵌图片；localStorage 空间不足仍会拒绝保存并保留原数据。
- 未自动删除未引用图片，避免影响其他标签页、取消编辑或旧记录；后续安全清理需要明确保留策略。
- 仅静态 PNG/JPEG/WebP 上传；HEIC、SVG、动画图仍不接受。
- 旧版从未记录的扣款锚点与成本历史不能完整重建；17 项服务仍使用中性 Logo；严格同时的跨标签 localStorage 写入仍受原有平台限制。
