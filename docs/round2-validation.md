# 第二轮界面修复与验收

本轮基于 `main` 的 `17164620b270abb6061316ced1d4f0c8e7d947e1`，在独立分支 `fix/service-icons-ipad-select` 开发。范围仅包括内置服务图标、首页添加入口及原生选择控件的生命周期；PR 审核前不合并、不发布。

## 问题与修改

- 内置图标来自多种图标集合，部分 SVG 含彩色填充、渐变、不透明背景或立体边缘，缺失图标使用了图片占位符。保留 55 个现有品牌资产的路径与识别轮廓，清理其中 8 个需要调整的资源，通过显示层区分内置图标与用户上传图片。内置图标浅色主题为深色、深色主题为浅色；17 项没有可靠图标的服务及加载失败均使用同一中性服务 SVG。来源、原始哈希与派生修改记录在 `assets/brands/manifest.json` 和 `docs/brand-assets.md`。
- 顶部按钮原先以“非设置页”为显示条件，因此列表、统计、日历重复出现。改为仅首页生成按钮 DOM；添加、编辑及数据处理逻辑保留。
- 设置 `change` 事件原先保存后重建 `#app`，然后主动 `focus()` 新下拉控件；汇率刷新也会重建并恢复焦点，PWA 状态更新会对面板之外的控件重复聚焦。这些路径会破坏原生菜单的生命周期。设置现在就地更新文字、偏好及选项，保留原下拉节点；统计模式也保留选择控件；后台更新避开正在操作的原生选择器，PWA 仅恢复自身被替换按钮的焦点。

以上定位来自代码、附带视频及自动化生命周期断言；没有把 Chromium 模拟结果视作真实 iPadOS 菜单验收。

## iPad 人工复测

**尚未完成真实设备验证。** 请在审核合并、发布成功并接受 PWA 更新后进行以下检查；PR 提交本身不会更新当前网站。

1. 在 iPad Safari 打开 `/sumi/`，进入设置。语言按“简体中文 → English → 日本語 → 繁體中文 → 简体中文”连续选择。每次选择后观察菜单自然关闭、文字立即更新且不自行重开；再次主动点控件应能正常打开。重复几轮，并测试点菜单外侧取消。
2. 对货币、主题、减少动态效果和提醒天数重复操作；切换语言后重新打开页面，确认语言与偏好保存。分别测试横屏、竖屏、触控与外接键盘。
3. 手动刷新汇率后立即打开语言或货币选择器，等待请求完成，确认菜单没有被关闭重开或焦点被抢走；模拟断网、恢复联网后重复。测试从下拉控件直接点导航或表单按钮，确认第一次点击有效。
4. 从首页添加订阅，检查币种、周期、状态、自动续费、类别建议及日期选择；编辑订阅和付款记录，确认可连续选择、关闭、重开、保存。统计页反复切换月份、年份、自定义范围。
5. 浅色／深色／跟随系统下检查服务搜索、Logo 选择器、卡片、详情及统计图标。已有自定义图片应保留颜色；无图标服务显示中性图形。新增一张图片，再重新打开页面检查。
6. 首页有添加按钮，列表、统计、日历、设置均无重复入口。安装到主屏幕后离线重开，检查图标与已有记录；保持手机首页紧凑且不显示柱状图。
